OUR LOVE HUB

FILES TO UPLOAD TO GITHUB (same folder, same repository):
  1. index.html   (this site)
  2. song.mp3     (YOUR song - the file name must be exactly: song.mp3, all lowercase)

HOW TO PUBLISH
  - github.com > New repository (Public) > Add file > Upload files > drag index.html and song.mp3 > Commit changes
  - Settings > Pages > Deploy from a branch > main > / (root) > Save
  - Your site: https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

HOW THE GIFT WORKS
  - Hama signs in, builds the bouquet in "Bouquet Studio", presses "Send to Sammy", copies the link and sends it to her.
  - Sammy opens that link, signs in as Sammy, and the gift box appears.
  - Use "Preview how Sammy will see it" to test without sending.

CHANGE THE SONG NAME OR FILE
  Open index.html in Notepad and edit the CONFIG block near the top of the script:
    songFile: 'song.mp3'
    songTitle: 'Our Song'
